otr4j:htmlreport

Full name:

com.soebes.maven.plugins:otr4j-maven-plugin:0.1.2-SNAPSHOT:htmlreport

Description:

This goal will generate the HTML report from the XML file provided by the previous unit- integration test execution.

Attributes:

  • Requires a Maven project to be executed.
  • The goal is thread-safe and supports parallel builds.
  • Binds by default to the lifecycle phase: test.

Required Parameters

Name Type Since Description
<htmlTestReportFile> String - Define the resulting HTML report file name.
Default: open-test-report.html
<outputDirectory> Path - Define the output directory for the generated HTML report.
Default: ${project.reporting.outputDirectory}
<xmlFile> Path - Define the default XML source file location.
Default: ${project.build.directory}/open-test-report.xml

Optional Parameters

Name Type Since Description
<skip> boolean - This will skip the execution of the plugin.
Default: false
<verbose> boolean - This will turn on verbose behavior and will print out all information.
Default: false

Parameter Details

<htmlTestReportFile>

Define the resulting HTML report file name.
  • Type: java.lang.String
  • Required: Yes
  • Default: open-test-report.html

<outputDirectory>

Define the output directory for the generated HTML report.
  • Type: java.nio.file.Path
  • Required: Yes
  • Default: ${project.reporting.outputDirectory}

<skip>

This will skip the execution of the plugin.
  • Type: boolean
  • Required: No
  • Default: false

<verbose>

This will turn on verbose behavior and will print out all information.
  • Type: boolean
  • Required: No
  • Default: false

<xmlFile>

Define the default XML source file location.
  • Type: java.nio.file.Path
  • Required: Yes
  • Default: ${project.build.directory}/open-test-report.xml
